# Banking Transaction Reporting System

## Overview
A database project built using Oracle SQL and PL/SQL to manage customers, accounts, banking transactions, audit logs, and reporting.

## Features
- Customer Management
- Branch Management
- Account Management
- Deposit Transactions
- Loan Management
- Audit Logging using Triggers
- Reporting using Views
- Performance Optimization using Indexes

## Technologies Used
- Oracle SQL
- PL/SQL
- SQL*Plus

## Database Objects Used
- Tables
- Constraints
- Joins
- Subqueries
- Procedures
- Functions
- Triggers
- Views
- Indexes
- Sequences

## Modules

### 1. Master Data
- Branches
- Customers
- Account Types

### 2. Account Management
- Create accounts
- Balance tracking

### 3. Transaction Processing
- Deposit transactions
- Transaction history

### 4. Reporting
- Customer transaction reports
- Branch reports

### 5. Audit Tracking
- Trigger-based logging
